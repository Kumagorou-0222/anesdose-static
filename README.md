# AnesDose — Public Static Distribution

このリポジトリは、AnesDoseの**ビルド済み静的配布ファイルのみ**を公開するためのものです。開発用ソースコードは非公開の開発リポジトリで管理しています。

> AnesDoseは教育・研究目的のPK/PDシミュレーターです。表示される値は数理モデルによる推定値であり、実患者への投与判断・投与設計・臨床判断には使用できません。

## 正規配布先

GitHub Pagesの公開URLを正規配布先とします。更新は非公開の開発リポジトリで検証後、このリポジトリへビルド済みファイルを反映して行います。

## 改変について

公開サイトの表示内容は閲覧・複製され得ますが、このリポジトリへの書込み権限を持たない第三者は正規版を変更できません。
